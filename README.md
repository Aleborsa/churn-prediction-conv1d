# Predição de Recompra no Varejo Online (CNN 1D)

Projeto de Ciência de Dados que aplica a metodologia **RFM** (Recency,
Frequency, Monetary) combinada com uma **Rede Neural Convolucional 1D**
para prever se um cliente fará uma nova compra nos próximos **90 dias**.

O pipeline cobre desde a limpeza dos dados brutos até a avaliação final
do modelo, incluindo baselines (Random Forest e Regressão Logística) para
comparação académica.

---

## 1. Pré-requisitos

- **Python 3.10+**
- **pip** atualizado
- Arquivo bruto `online_retail_II.xlsx` (dataset público "Online Retail II")
